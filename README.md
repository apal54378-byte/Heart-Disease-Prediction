# ❤️ Heart Disease Prediction using K-Nearest Neighbors (KNN)

## 📌 Project Overview

This project predicts whether a patient has heart disease using the K-Nearest Neighbors (KNN) machine learning algorithm. The dataset was preprocessed, analyzed, and used to train a classification model.

---

## 🎯 Objectives

- Perform data preprocessing
- Explore the dataset using EDA
- Train a KNN classification model
- Evaluate model performance
- Predict heart disease for new patient data

---

## 📂 Dataset

- **Source:** Kaggle
- **Dataset:** cardiovascular-disease-dataset

Download the dataset from Kaggle and place it inside the `dataset/` folder before running the notebook.
